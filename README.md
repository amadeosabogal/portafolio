# portafolio

Portafolio digital de **WODITEK** - Soluciones digitales, desarrollo de software a medida y aplicaciones web.

## 🚀 Tecnologías
- **React 19**
- **TypeScript**
- **Vite**
- **CSS3 Vanilla**

## 📦 Instalación y Uso
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar bundle de producción
npm run build
```
